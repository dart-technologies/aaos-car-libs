# PaintBooth: two @hide platform-API users, excluded by upstream via filter.excludes.
#
# ActivityTaskManagerImpl calls IActivityTaskManager and OverlayManagerImpl calls
# IOverlayManager.Stub.asInterface(ServiceManager.getService(...)). Neither interface exists in
# the public SDK — they resolve only against AOSP's internal android.jar, which this fork
# deliberately does not have on the boot classpath (removing -Xbootclasspath/p: was Phase 1).
#
# Consequence, stated rather than implied: PaintBooth's "current activity" and "overlays" demo
# screens are non-functional in this fork's build. The gallery runs; those two features do not.
# Restoring them needs either a system-signed build against internal APIs or a reimplementation
# on public APIs — neither is on the current roadmap.
