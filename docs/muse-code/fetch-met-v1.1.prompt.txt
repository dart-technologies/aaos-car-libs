Update scripts/fetch-met-open-access.py in this repository to the current Met Collection API (spec: https://metmuseum.github.io/). Modify only that file.

Facts from the spec:
- /public/collection/v1/search was retired on 2026-10-01 and now returns HTTP 410.
- Use https://collectionapi.metmuseum.org/public/collection/v1.1/search instead. Same filters (q, isHighlight, title, tags, departmentId, isOnView, artistOrCulture, medium, hasImages, geoLocation, dateBegin+dateEnd); q is optional.
- v1.1 pages with offset (zero-based, default 0) and limit (default 100, max 500); offset+limit must not exceed 10000. Response: total (all matches) and objectIDs (this page only). Ordering may differ from v1.
- /v1/objects/<id> is unchanged. Keep requests well under 80 per second.
